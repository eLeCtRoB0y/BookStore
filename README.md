# ЧитайГород — учёт товаров (демоэкзамен 09.02.07, вариант 1)

Настольное приложение на **C# / WPF (.NET 8)** с базой данных **SQLite**.

## Структура

| Папка / файл | Содержимое |
|---|---|
| `Database/BookStore.sql` | Скрипт БД: создание таблиц (3НФ, PK/FK) и загрузка данных из файлов import |
| `Database/BookStore.db` | Готовая база SQLite, созданная этим скриптом |
| `Docs/ER_diagram.pdf` | ER-диаграмма (таблицы, атрибуты, ключи, связи) |
| `Docs/Block_scheme.pdf` | Блок-схема алгоритма по ГОСТ 19.701-90 |
| `Docs/Отладка.docx` | Документ для скриншотов корректной работы |
| `src/BookStore.sln` | Решение Visual Studio |
| `src/BookStore.Data` | Модели, работа с БД (Microsoft.Data.Sqlite), поиск/фильтр/сортировка |
| `src/BookStore.App` | WPF-приложение: окна, стили, ресурсы, фото товаров (`Images`) |
| `publish.bat` | Сборка исполняемых файлов в папку `Release` |

## Запуск

1. Открыть `src/BookStore.sln` в Visual Studio 2022 (нужна рабочая нагрузка «Разработка классических приложений .NET»).
2. Запуск — F5. NuGet-пакет `Microsoft.Data.Sqlite` восстановится автоматически.
3. Исполняемые файлы: запустить `publish.bat` → `Release/BookStore.exe`.

Файлы `BookStore.db`, `BookStore.sql` и папка `Images` копируются рядом с exe.
Если `BookStore.db` удалить, при запуске база будет создана заново из `BookStore.sql`.

## Возможности по ролям

- **Гость, клиент** — просмотр списка товаров.
- **Менеджер** — плюс поиск (по всем текстовым полям, несколько слов сразу), сортировка по цене и
  количеству (по возрастанию/убыванию), фильтр по скидке (0–12,99 %, 13–16,99 %, 17 % и более),
  просмотр заказов. Поиск, фильтр и сортировка применяются вместе и сразу при вводе.
- **Администратор** — плюс добавление/редактирование/удаление товаров и заказов.
  Редактирование — нажатием на товар/заказ в списке, добавление — кнопками «Добавить товар»/«Добавить заказ».
  Одновременно открывается только одно окно редактирования. Товар, который есть в заказах, удалить нельзя.

Подсветка строк: скидка больше 25 % — фон `#23E1EF`; товара нет на складе — серый фон;
при скидке основная цена зачёркнута красным, рядом итоговая цена чёрным. Нет фото — заглушка `picture.png`.

Фото товара при сохранении уменьшается до 300×200, кладётся в папку `Images` рядом с программой,
в БД хранится путь к нему; при замене старый файл удаляется.

## Подготовка данных импорта

При переносе в БД исправлены ошибки исходных файлов:
- артикул `А112Т4` записан с кириллическими «А» и «Т» → `A112T4` (латиница, как остальные артикулы);
- дата заказа №7 `30.02.2024` не существует → `29.02.2024`;
- статус `«Новый »` с лишним пробелом → `Новый`;
- задвоенные значения: «Тайны и загадки отца БраунаТайны и загадки отца Брауна», поставщик «Янь Чуннянь Янь Чуннянь»;
  лишняя «v» в «Тысячелетие императорской керамикиv»; перевод строки перед «Лениздат»;
- адреса пунктов выдачи приведены к единому виду («г. Лесной, ул. …»), убраны неразрывные пробелы;
- состав заказа («Артикул, кол-во, …») вынесен в отдельную таблицу `OrderItem`, клиент заказа связан с `AppUser` по ФИО,
  пункт выдачи — по номеру строки в файле пунктов выдачи.

## Оформление (Приложение 3 «Руководство по стилю»)

- Шрифт Comic Sans MS; основной фон `#FFFFFF`, дополнительный фон (шапки, панели кнопок) `#ABCFCE`,
  акцент (кнопки целевых действий) `#546F94`; скидка больше 25 % — `#23E1EF`. Все цвета и шрифт заданы в `App.xaml`.
- У каждого окна свой заголовок; логотип на главной форме и формах выводится из исходного файла ресурсов
  без изменения изображения, пропорций и цвета.
- Файл `icon.ico` из ресурсов на самом деле PNG-картинка с расширением .ico — Windows не принимает такой файл
  как значок приложения, сборка падает. Поэтому то же изображение сохранено в настоящем формате ICO
  (`Resources/app.ico`, без искажения пропорций).
